# pitanil-media

Публичное хранилище медиа для публикаций агентства: обложки постов, слайды каруселей, видео.

**Зачем.** Планировщики (Metricool, Postmypost) принимают медиа только по публичным ссылкам, локальный файл им не отдать. Этот репозиторий даёт постоянные прямые ссылки вида:

```
https://raw.githubusercontent.com/<владелец>/pitanil-media/main/атомы/П01-контроль-веса/карусель/П01-С1-А03-слайд-1.png
```

## Правила

- **Только медиа для уже согласованного контента.** Репозиторий публичный: всё, что сюда попадает, видно всем и остаётся в истории git навсегда. Черновые и отклонённые варианты сюда не кладём.
- **Никаких текстов, брифов, документов клиента и тем более секретов.** Только картинки и видео.
- Имя файла = ID атома + смысл: `П01-С1-А03-слайд-1.png`. По имени всегда понятно, из какого атома медиа.
- Структура: `атомы/<пиллар>/<карусель|обложки|видео>/`.

## Как класть новое медиа

```bash
python3 "Агентство ПИТАНИЛ/04-Производство/_инструменты/медиа-хостинг.py" --add путь/к/файлу.png --атом П01-С1-А05 --тип обложки
```

Скрипт копирует файл, коммитит, пушит и печатает готовую raw-ссылку для планировщика.

## Связь

Основной vault агентства — приватный, лежит отдельно. Здесь только медиа.
